Campaign chips and trust badges

Use one chip per line. For trust badges, use icon|label|detail on each line.

Navigation menus

Header and mobile menus: one link per line as Label | URL, with an optional third part for flags — active marks the current-page link in the header, highlight gives it the campaign colour. Footer columns start with a # Column title line, followed by their Label | URL lines. Reorder lines to reorder the menu.

Static page intros

Override the main intro copy for support and legal pages without redeploying the storefront.
